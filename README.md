# مشكاة الفقه

تطبيق ويب تقدّمي (PWA) مفتوح المصدر يجمع الرسائل العملية لفقهائنا العظام، مع العروة الوثقى وتعليقاتها، ونخبة من الشروح المكتوبة والمسجّلة، و«جامع الاستفتاءات» لمقارنة آراء المراجع. يعمل بلا إنترنت بعد التحميل الأول، ولا يرسل أي بيانات: المفضلة والملاحظات والكتابات تبقى على جهاز المستخدم.

- **125 كتاباً** و**16 مرجعاً**
- **جامع الاستفتاءات:** 1466 مسألة و12873 جواباً من 18 مرجعاً (من عمل الشيخ عادل الجوهر، ويُشار إلى تطبيقه الأصلي برابط صغير داخل القسم)
- بحث بالعناوين والنصوص والحواشي، مفضلة بألوان، ملاحظات، كتب ومجموعات وكتابات خاصة، تقسيم الشاشة، إشعار «مسألة اليوم»

v82.js / v82.css      التعليمية، الجامع في القراءات، المشاركة والإشعارات الجديدة

v77.js                التراجع عن آخر إعداد، إشعار دخول الكتاب، شريط كتاباتي

## التشغيل محلياً

يلزم خادم ثابت (لا يعمل الفتح المباشر للملف):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التحديث والإصدارات

- **تغيير `app.js` أو `index.html` أو `vendor/`:** ارفع `SHELL_VERSION` في `service-worker.js` وقيمة `BUILD_VERSION` في `app.js`.
- **تغيير `books.db`:**
  1. ارفع `DB_VERSION` في `service-worker.js` و`EXPECTED_DB_VERSION` في `app.js`.
  2. أعد بناء فهرس البحث: `node tools/build_search_index.js`.

## ملاحظات النشر

- حجم `books.db` نحو **112 ميغابايت**، وهذا يتجاوز حدّ **100 ميغابايت** لملف واحد في GitHub. استخدم Git LFS، أو ارفعه ضمن «Releases» أو على استضافة ملفات، ثم تأكد أن مساره بجانب `index.html` (يُطلب باسم `books.db`).
- الاستضافة تحتاج HTTPS ليعمل الـ Service Worker والمشاركة والإشعارات.
- لم يُحدَّد ترخيص بعد: أضف ملف `LICENSE` يناسب المحتوى والكود قبل النشر.
