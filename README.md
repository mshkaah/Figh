# مشكاة الفقه

**الرسائل العملية للمراجع الكرام في تطبيق ويب يعمل بلا إنترنت**

[التشغيل](#التشغيل-محلياً) · [البنية](#بنية-المشروع) · [الإصدارات](#التحديث-والإصدارات) · [النشر](#النشر)

</div>

تطبيق ويب تقدّمي (PWA) مفتوح المصدر يجمع الرسائل العملية لفقهائنا العظام، مع العروة الوثقى وتعليقاتها، ونخبة من الشروح المكتوبة والمسجّلة، و«جامع الاستفتاءات» لمقارنة آراء المراجع. يعمل بلا إنترنت بعد التحميل الأول، ولا يرسل أي بيانات: المفضلة والملاحظات والكتابات تبقى على جهاز المستخدم.

## المزايا

- **125 كتاباً** و**16 مرجعاً**.
- **جامع الاستفتاءات:** 1466 مسألة و12873 جواباً من 18 مرجعاً، من عمل الشيخ عادل الجوهر، ويُشار إلى تطبيقه الأصلي برابط داخل القسم.
- بحث في العناوين والنصوص والحواشي، مع سجل واقتراحات وترتيب للنتائج.
- مفضلة بألوان، وملاحظات، وكتب ومجموعات وكتابات خاصة بتصدير PDF.
- مشاركة النص أو صورة بهوية التطبيق.
- تقسيم الشاشة، وتذكيرات، وإشعار «مسألة اليوم»، وسلة محذوفات تُسترجع خلال 30 يوماً.
- وضع فاتح وليلي، وتعليمات تفاعلية تعرّف بالإيماءات.

## بنية المشروع

```
.
├── index.html             واجهة التطبيق
├── service-worker.js      العمل بلا إنترنت والتحديثات
├── manifest.json          إعدادات التثبيت (PWA)
├── books.db.part1/part2   قاعدة البيانات (SQLite) مقسومة جزأين، تُدمج في المتصفح وتُحمَّل بـ sql.js
│                          (أو books.db كاملاً إن لم تُوجد الأجزاء)
├── search-index.bin       فهرس بحث مُسبق يُولَّد من books.db
├── css/                   التنسيقات
├── js/                    السكربتات
├── icons/                 أيقونات التطبيق وصور المراجع ومخططات الشروح
├── vendor/                مكتبات محلية: sql.js، الخطوط، أيقونات Tabler
├── tools/                 أدوات البناء (لا تُحمَّل في التطبيق)
└── docs/                  سجل الإصدارات وتقارير الفحص
```

| `reader-select.js` | نظام التحديد والتظليل في القارئ |
| `recents.js` | «القراءات»: سجل آخر المواضع |
| `reminders.js` | تذكيرات المفضلة والملاحظات |
| `trash.js` | المحذوفات |
| `share81.js` | المشاركة كنص أو صورة |
| `writing-view.js` | قراءة الكتابات والقوالب وتصدير PDF |
| `hints.js` · `coach.js` · `coach-hand.js` · `discover.js` · `discover-guide.js` | نظام الاكتشاف والتعليمات والمرشد |
| `urwa_toc.js` | فهرس العروة الوثقى |

| `jami.js` | منطق جامع الاستفتاءات: طيّ السؤال وإظهاره (بأزرار فقط)، قياس منطقة الباب والتقليب، القفز إلى المرجع |

## التشغيل محلياً

يلزم خادم ثابت، ولا يعمل الفتح المباشر للملف:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التحديث والإصدارات

- **تغيير ملفات التطبيق (`js/` أو `css/` أو `index.html` أو `vendor/`):** ارفع `SHELL_VERSION` في `service-worker.js` و`BUILD_VERSION` في `js/app.js`.
- **تغيير `books.db`:**
  1. ارفع `DB_VERSION` في `service-worker.js` و`EXPECTED_DB_VERSION` في `js/app.js`.
  2. أعد بناء فهرس البحث: `node tools/build_search_index.js`.
- يُضاف لكل إصدار سطره في [`docs/CHANGELOG.md`](docs/CHANGELOG.md).

## النشر

- **GitHub Pages:** يكفي تفعيله من إعدادات المستودع على الفرع الرئيسي؛ الملف `.nojekyll` موجود.
- **حجم `books.db`:** نحو **112 ميغابايت**، وهذا يتجاوز حدّ **100 ميغابايت** للملف الواحد في GitHub. استخدم [Git LFS](https://git-lfs.com) أو استضف الملف خارجياً، وتأكد أن مساره بجانب `index.html` (يُطلب باسم `books.db`).
- **أجزاء القاعدة:** الملفان `books.db.part1` و`books.db.part2` (أو `books_part1.bin` و`books_part2.bin`) يوضعان بجانب `index.html`، ويدمجهما التطبيق تلقائياً ويتحقق من اكتمال الحجم. لبناء الفهرس أو الأدوات: `cat books.db.part1 books.db.part2 > books.db`.
- الاستضافة تحتاج **HTTPS** ليعمل الـ Service Worker والمشاركة والإشعارات.
